# Temiloluwa Daniel Jibowu · Engineering Portfolio

**Live site:** https://temiloluwadanieljibowu.github.io/

Hi, I'm Temiloluwa Daniel Jibowu, an Electrical Engineering student at UT Arlington, class of 2027. This repository holds my portfolio website: embedded systems, hardware integration and wireless communication projects, each written up as a case study (problem, engineering decisions, implementation, testing and results).

## How it's built

- Plain HTML, CSS and JavaScript. No frameworks, no build step.
- All of the text lives in one file, `data/content.js`; `js/components.js` turns it into the page.
- A dark theme and a light theme, a canvas starfield, and an interactive orbit of interests.
- Accessible by design: keyboard navigation, visible focus, alt text, and "reduce motion" support.
- Fonts: [Geist and Geist Mono](https://vercel.com/font) (SIL Open Font License).
